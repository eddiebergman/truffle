Theme files in this folder come from tm-themes 1.10.12 (https://github.com/shikijs/textmate-grammars-themes).
GitHub Dark and GitHub Light are the upstream github-dark-default and github-light-default files.
Each file adds a "truffle" palette block picked from its own colours.
