Connections & settings

Credentials stay on the server. Sync reads your remote work. PR actions write to GitHub only when you select them.

GitHub

Uses your GitHub CLI login. In a terminal, run:

gh auth login

Or set GITHUB_TOKEN in the project’s .env file. Includes open PRs you authored, are assigned, or were asked to review, plus issues assigned to you.

Linear

Create a personal API key with read access in Linear → Settings → Security & access. Add it to .env:

LINEAR_API_KEY=your_key_here

Restart the server after changing credentials. Includes active issues assigned to, created by, subscribed to, or commented on by the key’s owner, including Triage and issues without a project.

Sentry

Reads unresolved errors from all accessible projects, seen within the last 90 days. Uses your server’s ~/.sentryclirc credentials from sentry-cli login.

Connection setup & optional overrides

Set SENTRY_ORG=your-org in .env. An optional SENTRY_AUTH_TOKEN overrides the CLI credential. Use a read-only token. SENTRY_STATS_PERIOD=90d accepts 1–90 days. Restart after configuration changes.

Sentry errors and Linear tickets are separate records. Linear tickets retain their linked error URLs. Automatic ticket creation depends on your Sentry alert rules.
